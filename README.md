# Minecraft Portfolio

My personal portfolio — an immersive, Minecraft-inspired three.js website.

## 🙏 Credit

The design, 3D scene, and original code for this portfolio were created by
**[Andrew Woan](https://github.com/andrewwoan)**. His award-winning original
project lives here: **[woan-minecraft-folio](https://github.com/andrewwoan/woan-minecraft-folio)**
([live site](http://woanminecraftfolio.com/)).

This repo is my own build on top of his work, with the content adapted to me.
Full credit for the design and engineering goes to Andrew. His original MIT
license is preserved in [`LICENSE.md`](LICENSE.md).

Andrew's awards for the original:
- [FWA of the Day](https://thefwa.com/cases/educational-minecraft-folio)
- [Awwwards Honorable Mention](https://www.awwwards.com/sites/educational-minecraft-folio)
- [CSSDA Special Kudos + Best UI/UX/Innovation](https://www.cssdesignawards.com/sites/educational-minecraft-folio/46808/)
